# English_Translation

Required guideline files in this folder:

- `translator.ipynb` — executed verification notebook (CSV-only)
- `translation_examples.csv` — 12 original / text_translated_en pairs

`translated_en_posts.csv` was **not** dumped as a 742,942-row spreadsheet. The column `text_translated_en` lives in `data/nlp_analysis_corpus.db` table `nlp_posts` and is a byte-for-byte copy of `original_text` for every scored post. That database is excluded from the upload (1.30 GB).

They do not require the excluded files to open and show results.
